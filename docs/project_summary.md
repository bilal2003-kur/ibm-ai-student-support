# Project Summary

This project was created by Bilal Kurabi to explore how artificial intelligence can be applied to a real-world educational challenge.

The system uses student data such as attendance, assignment performance, quiz performance, participation, and study hours to predict whether a student may need academic support. Using a machine learning model, the project demonstrates a practical AI workflow that can be understood by both technical and non-technical audiences.

The aim is to show a realistic and professional approach to AI application in education. It highlights how data-driven decision-making can help institutions support students earlier and more effectively.

This project is especially useful for students building a portfolio because it demonstrates:
- practical AI and machine learning understanding
- real-world problem solving
- data analysis skills
- clear project presentation
- professional GitHub documentation
