# IBM AI Student Support System

A practical AI project designed to support students by predicting academic performance and identifying learners who may need extra guidance. This project demonstrates how artificial intelligence can be applied in education to improve student outcomes, support early intervention, and provide more personalised academic support.

This project was developed by Bilal Kurabi as a portfolio-ready solution for employers, academic reviewers, and future opportunities in AI, data science, and software development.

## Project Overview

Educational institutions often face difficulty identifying students who may need additional academic support before performance declines. Manual reviews are time-consuming and inconsistent, and many students can fall behind without early assistance.

This project addresses that challenge by using machine learning to analyse student performance data and predict whether a student may need academic support. The goal is to provide a simple, effective AI-driven solution that supports decision-making in education.

## Problem Statement

Students can struggle with academic progress for many reasons, including low attendance, weak assignment performance, poor quiz results, low participation, and limited study habits. Without early support, these issues can become persistent and affect long-term academic outcomes.

The problem is not just about identifying poor performance, but also about detecting risks early and helping students receive support before they fall too far behind.

## Solution

The IBM AI Student Support System analyses key educational indicators such as:

- attendance
- assignment score
- quiz score
- participation
- study hours

Using these inputs, the system trains a machine learning model to predict whether a student is likely to need academic support. This allows academic advisors or educational staff to make more informed, data-driven decisions.

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/bilal2003-kur/ibm-ai-student-support.git
cd ibm-ai-student-support
```

### 2. Create a virtual environment

```bash
python -m venv venv
source venv/bin/activate   # Mac/Linux
venv\Scripts\activate      # Windows
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the project

```bash
streamlit run app.py
```
